# Pravila za ovaj projekat

- Projekat je sajt Simon d.o.o., objavljen na GitHub Pages iz repozitorijuma rakiclukadesign-code/simon- (grana main).
- Posle svake završene izmene: proveri da sajt radi i da u konzoli nema grešaka, pa uradi git commit sa kratkom porukom na srpskom koja opisuje izmenu i git push na main.
- Pre svakog push-a uradi git pull, da preuzmeš izmene koje su možda napravljene direktno na GitHub-u.
- Ne pravi commit ako izmena nije završena ili ako postoje greške.
- Nikad ne koristi git push --force, ne briši istoriju i ne briši fajlove sa GitHub-a bez pitanja.
- Na kraju svake izmene napiši mi šta je promenjeno i link do sajta: https://rakiclukadesign-code.github.io/simon-/
